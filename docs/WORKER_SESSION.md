# Worker Session Isolation

Authenticated HTTP session DTOs now include an opaque `clientContext` and the server's `expiresAt`. The context is a domain-separated digest of the private session identity and current worker language or staff role, not the cookie/token hash itself. It cannot authenticate a request: the HttpOnly cookie, active principal, grant, scope and domain checks remain required. No schema migration or live-provider call is involved.

Both SQLite and PostgreSQL HTTP adapters require the page context for worker answer/help/audio mutations and worker logout. Any supplied context, including on a read or staff logout, must match the authenticated session before the body or recording is accepted. The old worker page therefore cannot use a different newly signed-in worker/staff cookie to submit or revoke that person's session. Worker inbox/detail reads also send their original context. Missing or mismatched contexts return the generic `409 Session context changed`; expired/revoked authentication still fails first.

The worker client listens for same-origin session-change signals, foreground/online rechecks, visible-page polling and the server expiry time. Broadcast payloads contain only `changed`; a storage fallback contains only a random signal ID. The initial mount also rechecks identity. A changed/expired/malformed/unavailable session locks the old worker view and unmounts its typed/help/capture state. It never automatically adopts another identity. Speech playback is stopped on unmount; the existing recorder cleanup releases its resources. Requests already sent may still complete, which the localized lock notice states explicitly. New dispatches from a locked worker page are blocked.

This is not durable offline storage or a browser/device-wide erasure claim. Polling is not instantaneous when no cross-tab signal is available; foreground/expiry and server mutation fences remain necessary. An unavailable session check intentionally discards memory-only drafts rather than displaying private worker content under an unverified identity. Browser-native navigation, hardware capture cleanup, frozen/background timer behavior, all staff cross-tab views and complete offline/shared-phone expiry remain separate gates.
